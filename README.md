# Yukun He

Personal website at https://yukunhe16.github.io/.

A small, buildless HTML/CSS site. Edit `index.html` for content and `styles.css` for appearance. GitHub Pages publishes the root of the `main` branch.

## Local preview

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.

Fonts are self-hosted. DM Sans and Montserrat are distributed under the SIL Open Font License; see `assets/` for their licenses. The visual direction is inspired by the DeepSeek Harness landing page, with original layout and artwork.
